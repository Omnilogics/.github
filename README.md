# Omnilogics Community Health & Default Configurations

This repository (`Omnilogics/.github`) provides default community health files, issue templates, and configurations across the entire **Omnilogics** organization on GitHub.

## Overview

Files defined in this repository automatically apply to all public and private repositories in the `Omnilogics` organization that do not define their own repository-specific templates.

### Included Templates & Configurations

- **Bug Report Form** ([`bug_report.yml`](file:///Users/dinethsiriwardana/Downloads/Omnilogics%20Github/.github/.github/ISSUE_TEMPLATE/bug_report.yml)): Structured issue form with reproduction steps, environment context, and verification checklists.
- **Feature Request Form** ([`feature_request.yml`](file:///Users/dinethsiriwardana/Downloads/Omnilogics%20Github/.github/.github/ISSUE_TEMPLATE/feature_request.yml)): Structured issue form for proposals, problems, and proposed solutions.
- **Template Configuration** ([`config.yml`](file:///Users/dinethsiriwardana/Downloads/Omnilogics%20Github/.github/.github/ISSUE_TEMPLATE/config.yml)): Disables blank issues to enforce structured input and directs general questions to GitHub Discussions.

## Overriding Defaults

Any individual repository can override these organization defaults by placing its own templates inside its local `.github/ISSUE_TEMPLATE/` directory.
